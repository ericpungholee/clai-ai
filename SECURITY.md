# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting when it is available for this repository. If it is unavailable, open an issue that asks for a private contact channel without including exploit details or credentials.

Include the affected component, reproduction steps, impact, and any suggested mitigation. You should receive an acknowledgement within seven days.

## Supported versions

Security fixes are applied to the latest commit on `main`. This portfolio project is designed for local, single-user use and does not provide authentication or authorization controls.
