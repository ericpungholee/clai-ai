# Clai

Clai is a graph-based workspace for AI-assisted 3D product design.

This repository contains the application foundation: a Next.js frontend, FastAPI
backend, PostgreSQL, Redis, and a Celery worker. Product features are not
implemented yet.

## Setup

Requirements:

- Docker with Compose v2
- Node.js 22+, Python 3.12+, and [uv](https://docs.astral.sh/uv/) for
  development outside Docker

Create the local environment file:

```bash
cp .env.example .env
openssl rand -hex 24
```

Paste the generated value into `POSTGRES_PASSWORD`. Docker Compose builds the
database URL for containers. Set `DATABASE_URL` only when running backend tools
on the host. S3 and Tripo variables are reserved for future integrations.

```bash
make dev
```

Open:

- App: http://localhost:3000
- API: http://localhost:8000
- API docs: http://localhost:8000/docs
- PostgreSQL: `localhost:5432`
- Redis: `localhost:6379`

## Commands

```bash
make dev                         # build and start the stack
make down                        # stop the stack
make logs                        # follow service logs
make test                        # backend tests and frontend lint
make lint                        # Ruff and ESLint
make migrate                     # apply migrations
make revision MSG="add widgets"  # create an autogenerated migration
make backend-shell               # open a backend shell
make db-shell                    # open psql
```

PostgreSQL data persists across `make down`.

## Structure

```text
frontend/             Next.js App Router, TypeScript, Tailwind
backend/
  app/
    api/              FastAPI routes
    core/             settings and database connection
    models/           SQLAlchemy models
    schemas/          API schemas
    services/         application services
    workers/          Celery application and tasks
  alembic/            database migrations
  tests/              backend tests
docker-compose.yml    local services
```

`GET /health` checks the API process. `GET /health/ready` verifies PostgreSQL
and Redis connectivity.
